# Skill与机器接续

包内`hetu-biography-studio`通过河图稳定plugins.inspect、capabilities和skills.read动态发现，不创建Codex插件或独立MCP服务。安装／升级／启用后重新发现，旧包绑定不能继续使用；工具可见不等于获权读取任何作品。

默认旅程：固定史料／采访→独立人物与身份辨析→明确或未知时间事件→选择叙述章节→对照不同证词→新材料影响复核→传记阅读本。方法选择、阅读范围和判断依据由外部Agent负责，专业确定性规则由本包执行。先读现有成果和公开意见，不能为了演示创建另一份工程替代接续。

日期保留原文字面。首版normalize_date仅解释公历YYYY、YYYY-MM、YYYY-MM-DD、明确范围与before/after；about/不确定、未知历法与纪年不猜换算。严格校验闰日和上下界。不同人物即使同名也保持独立ID，身份关系是有证据的声明，冲突并列显示。事件可以保留互相矛盾的说法；时间检查只在区间明确不相交时判定先后。章节固定事件组合摘要，生平信息变化后旧叙述与意见待复核，不重写旧事件证据。

保存保留CAS与原键，未知先get_operation，成功后回读固定修订。每阶段准备create_handoff的固定依据与下一步问题；其他专业插件按实际安装Schema独立发现，缺能力不能伪造交接成功。费用、外发、正文采纳、正式设定和定稿沿作者真实决定处理。

Skill入口保持精炼，专业方法归references/workflows，操作地图由正式清单生成。专业清单和Schema由本仓库维护，宿主地图只导航公共入口。

身份辨析修正通过新声明的supersedes_id显式指向同一对人物的旧声明；原记录保持，不允许自指或循环。当前冲突只在未被明确取代的声明上检查，工作面仍展示全部历史。不同于按数组位置自动选择最后一次说法。
