# 传记工坊

> 河图洛书专业插件，围绕人物生平组织身份、事件、时间范围、不同证词与叙述章节，让传记修订有据可循。

## 简介

传记跨越多个时期、同名人物和不同证词。把未知日期补成精确日期、把同名者自动合并，都会让后续叙述建立在虚假确定性上。软件保存人物身份、原始证据和时间边界，Agent构造叙事，作者选择如何解释与讲述。

外部Agent经河图稳定CLI/MCP操作，作者阅读、比较与提意见。包内Skill随活动插件发现，专业成果、来源及修订可继续使用。

## 快速上手

Node.js 25、npm及河图0.12.6或更新版本。

```bash
npm ci
npm run build
npm run check
npm run test:unit
npm run package
```

正式宿主和运行包由acceptance-lock.json固定，安装后从河图稳定入口发现本包，不另安装Codex插件。

## 边界

不是族谱账户、人物搜索或自动事实认证服务；不自动从互联网补齐人物资料，不合并宿主正式人物。纪实插件核对文章主张，传记插件维护跨生平的身份和时间叙述。
